Build a Python-based AI Smart Traffic Management prototype with the following pipeline:

1. VEHICLE DETECTION & CLASSIFICATION
   - Use YOLOv8 (ultralytics) pretrained on COCO, fine-tuned or filtered for 
     classes: car, bus, truck, motorcycle, bicycle.
   - Input: recorded traffic video (mp4) or a public dataset (e.g., UA-DETRAC, 
     or a sample intersection video).
   - Output: bounding boxes + class labels per frame, vehicle count per lane 
     (define 2-4 lane ROIs as polygons on the frame).

2. TRAFFIC DENSITY & QUEUE ESTIMATION
   - For each lane ROI, compute: vehicle count, weighted density 
     (car=1, bus/truck=2.5, bike=0.5 — approximate road-space occupancy), 
     and queue length (distance from stop line to last stationary vehicle).
   - Track vehicles across frames using a simple tracker (ByteTrack or 
     Deep SORT via ultralytics' built-in tracking) to distinguish moving 
     vs. queued/stationary vehicles.

3. ADAPTIVE SIGNAL CONTROL LOGIC
   - Implement a rule-based baseline first: green time = base_time + 
     (k * weighted_density), capped at min/max bounds.
   - Then implement a simple Q-learning agent where:
     - State = discretized density levels per lane (e.g., low/med/high) 
       across all approaches at the intersection
     - Action = which lane gets green + for how long (discretized: 
       15s/30s/45s/60s)
     - Reward = negative of total waiting time / queue length across 
       all lanes
   - Train/simulate this in a lightweight custom simulator (not SUMO, 
     unless you want to integrate SUMO for realism) using the density 
     data extracted from step 2 as simulated traffic flow input.

4. EVALUATION
   - Compare: fixed-time signal (baseline) vs rule-based adaptive vs 
     RL-based adaptive.
   - Metrics: average waiting time per vehicle, total throughput, 
     max queue length, detection accuracy (mAP), processing time (FPS).
   - Plot results as comparison charts.

5. DASHBOARD (optional but good for demo)
   - A simple Streamlit or Flask dashboard showing: live annotated video 
     feed, per-lane density bars, current signal state, and a running 
     waiting-time comparison chart.

Structure the code into clear modules: detection.py, tracking.py, 
density_estimator.py, signal_controller.py (rule-based), rl_agent.py 
(Q-learning), simulator.py, evaluate.py, dashboard.py.
